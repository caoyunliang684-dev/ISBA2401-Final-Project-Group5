# ISBA2401-Final-Project-Group5
Final project for ISBA 2401 - Data Analytics with Python Group 5

## Run the H2 notebook

Clone this repository with GitHub Desktop to download the full datasets, including the large Food Balance Sheets CSV. For a command-line clone, install Git LFS and run the following commands.

```sh
git lfs install
git clone https://github.com/caoyunliang684-dev/ISBA2401-Final-Project-Group5.git
cd ISBA2401-Final-Project-Group5
```

From the repository folder, install the Python dependencies and open the notebook.

```sh
python -m pip install jupyterlab pandas matplotlib openpyxl
python -m jupyterlab H2_Initial_Finding.ipynb
```

The notebook reads the Food Security and Food Balance Sheets datasets and the OGHIST income classification workbook.
